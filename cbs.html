CBS is a two-level search algorithm

A high level to resolve conflicts, and a low level to plan paths.

We start by computing an initial path for each robot independently using A* search, without considering conflicts between robots.

Then we check for conflicts.

We organize the search using a Conflict Tree. Each node in this tree represents:

  • a set of constraints
  • a set of paths satisfying those constraints
  • the conflicts detected in those paths

We use a best-first search strategy according to the objective (makespan or flowtime).

If a node contains no conflicts, it is a solution node.

Otherwise, we select a conflict to resolve. We choose the earliest conflict first, and prioritize vertex conflicts over swap conflicts.

To resolve the conflict, the algorithm creates two child nodes. Since a conflict is between two agents, the branching factor is 2.

Each child adds a constraint for one of the conflicting robots.

For example: forbid a robot from being in a specific cell at a specific time, or forbid it from traversing a specific edge.

After adding the constraint, CBS replans only the affected robot using constrained A* search.

And we continue the search.
